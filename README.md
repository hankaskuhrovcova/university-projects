# University Projects

This repository contains selected university projects completed as part of my Computing for Business degree.

I created this repository to document some of the larger projects I have worked on during my studies and to show how my technical skills have developed across different modules.

The repository includes both individual and group projects. For group projects, the complete project may be included so that the application can be viewed as intended, while each project README clearly identifies my individual contributions.

## Current Projects

### Dublin Paws Animal Shelter

A multi-page front-end website developed as a four-person university group project.

The website was designed for a fictional animal shelter and includes features such as:

- Adoptable animal listings
- Animal filtering and favourites
- Adoption request form
- Success stories
- Newsletter registration
- Contact form
- Event calendar
- Volunteer information
- Donation page
- Lost pets section
- Responsive navigation and styling

My main contributions included the **Adoptable Pets** and **Success Stories** sections, where I worked with HTML, CSS, JavaScript, Bootstrap and Tailwind CSS.

[View Dublin Paws Animal Shelter](./dublin-paws-animal-shelter/)
