# Dublin Paws Animal Shelter

Dublin Paws Animal Shelter is a front-end website developed as a four-person university group project.

The project was designed as a fictional animal shelter website where users can browse animals available for adoption, read adoption success stories, find lost pets, view events, learn about volunteering, make donation enquiries and contact the shelter.

## Team Project

This project was completed by a team of four students.

The repository contains the complete website produced by the group, including work completed by all team members.

## My Contributions

My primary responsibility was the development of the:

### Adoptable Pets Page

I designed and developed the Adoptable Pets section, including:

- Animal listing cards
- Filtering by animal type, gender, size and age
- Favourite/like functionality
- Option to view favourite animals
- Dynamic count of currently displayed animals
- Adoption request form
- Responsive page styling and layout

### Success Stories Page

I designed and developed the Success Stories section, including:

- Individual animal adoption stories
- Responsive page layout
- Scroll-based image changes
- Dynamic image behaviour using JavaScript and the Intersection Observer API

I also worked with the shared design and navigation structure to ensure my pages were visually consistent with the rest of the website.

## Running the Project

No build process is required.

Clone or download the repository and open:

```text
index.html
```

in a web browser.

An internet connection is required for some externally loaded resources such as Bootstrap, Tailwind CSS, Font Awesome and Google Fonts.
